# One-Star Review of Something Essential — entry

A program/v1 entry for the make.fun "One-Star Review of Something
Essential" bounty. `main.py` writes one single-line one-star review
(135 characters) to `/output/entry.txt` (or to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).

The final review:

> One star for gravity. It catches every phone, plate and mug I have ever dropped, instantly, at full speed. It has never once caught me.

Gravity provides flawless, instant service to every object the
reviewer has ever dropped — and has never once extended that
service to the reviewer. The complaint is filed completely
deadpan, and the whole review turns on its last two words. See
`CANDIDATES.md` for the twelve draft candidates this winner was
picked from and the second-pass refinement.

Run it with: `python3 main.py`
